# SigmaOS-office

Unified productivity-suite and style-integration component for SigmaOS, covering
OpenOffice, LibreOffice, GenOffice, OnlyOffice, and CraftOffice workflows.

## Development

Use the repository Makefile for supported checks:

```bash
make build
make test
```

Keep application integration optional, reproducible, and isolated from the
boot-critical system. Track compatibility and licensing decisions explicitly.
